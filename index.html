SymPy Calc is SymPy with a calculator's syntax on top: everything below is a shortcut, and anything SymPy or Python can do works as written. shift menu lists the common functions.

The keypad

soft keys
The labels on the screen's bottom edge, in two rows: the blank keys under the screen do the lower ones, shift and the key the upper ones (or tap a label). They show a menu, what you can do with a selected result, or the names that start with what you're typing. Dots under them mean more pages: shift ▲ ▼, or a swipe on the labels, turns them
menu trig
menu lists the menus (calc, alg, num, matrix, stat; with shift: trig, vars, catalog, setup, help); again, it goes back to the one you were in. trig has a key of its own (shift trig: the hyperbolic ones), and shift = the comparisons. All of them come from menus.json
shift
Then a key: what's printed above it on the left (√ eˣ [ ] : i (−) ∞ E; undo on ⌫, your variables on x, the catalog on menu, clearing the tape on esc, the chars menu on alpha). Holding a key does the same, and so does shift-clicking it with a mouse
alpha
Then a key: its letter, on the right (a on menu, b on trig, then down the rows to v; w y z on 0 . ans; x has its own key), a capital with shift too. Twice keeps typing letters until alpha again (A-LOCK); the arrows stay arrows. Option-click types one with a mouse
shift alpha
The chars menu: a space, _ (for names like x_1), $, ;, quotes, ! % { } | &; on its second page ~ @, Greek letters (θ φ α ω λ…, which SymPy shows as Greek) and abc, the phone's own keyboard (123 puts it away)
shift enter
Evaluate, showing the result as a decimal; on an empty line, the last result as a decimal (or exact again)
▲ ▼
Earlier entries. Then ◀ ▶ show a result exact, as a decimal or in degrees, enter inserts it (or tap it; tap again to let go), ⌫ deletes it
esc ⌫
Back out one step (alpha, then a view or a selection, then the line); delete before the cursor. shift esc clears the whole tape, and shift ⌫ brings it back
catalog
All the functions (shift menu; after a name half typed, it opens there). ▲ ▼ move, the soft keys pick a group, enter inserts, ▶ opens the function's help, where the soft keys go to related ones and ◀ comes back. It opens with the letters on (A-LOCK): type a few to jump to a name
setup, vars, help
Take over the screen too: ▲ ▼ move, ◀ ▶ change a setting or help's section, enter picks, esc goes back. A keyboard's arrows, ⏎, Esc and ⌫ do the same
drag, pinch
On an iplot graph: pan, zoom
home screen
Share → Add to Home Screen on iOS (Install on Android) keeps it a tap away and runs it without the browser around it. It still loads Python from the network the first time

Typing math

2x   sin x   x^2   5!
Multiplication and function calls can be implied; ^ is a power
xy   velocity
One name each. x y or x*y multiplies
e   pi   I   oo
Constants: 2.718…, π, √−1, ∞
x   velocity
A name that isn't defined is a symbol; k m n are integers, f g h functions
sin(30°)
Degrees
1E3   6.02E23
A power of ten: 1E3 is 1000 exactly, 6.02E23 a decimal (shift ans types the E)
ans   $3
The last result; the result of entry 3. Typing + - * / ^ first continues from ans (-- for a negative number)

Assignment and equations

What's left of = decides what it means:

a = 3/7
A name: assign a variable (a := 3/7 too)
a, b = 1, 2
Several names: assign each
f(x) = x^2 + 1
A name with arguments: define a function
A[0, 1] = 5
A name with an index: change part of a variable; earlier results keep their values
x^2 = 4
Anything else: an equation
solve(x^2 = 4, x)
Inside brackets, = is an equation too…
solve(x^2 - 4, x, dict=True)
…except after a bare name, which is a keyword argument
x == 2
Asks whether both sides are the same expression: True or False

Variables and functions defined this way are kept when you reload; Python definitions (def) are not. :vars lists them.

Matrices and vectors

M[1, 2, 3]
A matrix with one row
A = M[[1, 2], [3, 4]]
A matrix from its rows
v = V[1, 2]
A column vector
A^-1   A*A   A*v   2v
Inverse, products, scaling
det(A)   A.T   A.eigenvals()
Any SymPy matrix function or method
v.dot(w)   v.cross(w)
Products of two vectors
A[0, 1]   A[1, :]   A[:, 0]
An element, a row, a column (counting from 0)
A[0, 1] = 5   A[1, :] = M[7, 8]
Change an element or a row; earlier results keep their values

[1, 2, 3] is a Python list: 2*[1, 2] is [1, 2, 1, 2]. M and V are names like any other: M = 3 replaces them until you forget it in :vars.

Graphs

iplot(sin(x)/x)
An interactive graph (of several functions: iplot(f, g, (x, 0, 2pi))). A range takes brackets too: iplot(x, [x, -10, 10])
drag   pinch   double-click
Pan (or swipe sideways); zoom; back to the start. Shift+drag zooms into a range
↑ then ← → + − 0
With the graph selected: pan, zoom, back to the start
plot(sin(x), (x, -5, 5))
A picture (matplotlib), with all of its options; also plot_parametric, plot_implicit
plt.plot(xs, ys)
Data rather than expressions: plt is matplotlib's pyplot, ready to use (plt.scatter, plt.bar, plt.hist…)

Python

Underneath, this is Python with SymPy, running in your browser. A line that starts with def, for, import… or isn't calculator syntax runs as Python, where = is Python's assignment. One line at a time: separate statements with ;.

def g(x): y = x + 1; return 2*y
A Python function
for i in range(3): print(i)
Loops; printed output shows on the tape
import math
Imports
def sq(n): return n**2
Python lines are plain Python: ** is a power and ^ is XOR, and nothing is implied (2*x, not 2x)

With a keyboard

A computer's keyboard types into the line, and works the views as the keypad does.

⏎
Evaluate; on an empty line, repeat the last one
⇧⏎
Evaluate, showing the result as a decimal; on an empty line, the last result as a decimal (or exact again)
↑ ↓
Select tape items, then: ⏎ insert, f exact/float, d degrees, ⌫ delete
⇧↑ ⇧↓
Select several cells (or Shift+click)
c   ⇧C
Copy the selected cells as text (sqrt(8) and = 2*sqrt(2)); copy the selected item's LaTeX
⌃Z
On an empty line: undo deleting an entry, forgetting a variable, or :clear (not :reset)
Tab
Complete a name
?
On an empty line: the function catalog
⌃M
Math input
⌃C
Stop a long computation
