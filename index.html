Press ? for the function catalog; type :help for how to type things.

SymPy runs in your browser. The first visit downloads it (about 10 MB); after that it's cached.

    Lists, vectors and matrices

    A list is a list, until you do math with it: then [1, 2, 3] is a vector. A list of equal-length rows, [[1, 2], [3, 4]], is a matrix, and shows as one.

    2[1, 2, 3]
    [2, 4, 6]
    [1, 2] + [3, 4]
    [4, 6]
    M = [[1, 2], [3, 4]]
    A matrix to use below
    M^-1   M*M   M.T
    Inverse, product, transpose
    M*[1, 1]
    Matrix times vector: [3, 7]
    det(M)   M.eigenvals()
    Any SymPy matrix function or method
    v.dot(w)   v.cross(w)
    Products of two vectors; v*w is an error
    M[0, 1]   M[1]   v[0]
    An element (2); a row ([3, 4]); an entry
    [k^2 for k in range(5)]
    [0, 1, 4, 9, 16]: comprehensions make lists too
    len(v)   sum(v)   max(v)
    List functions still work

    [0]*3 is [0] (math), not Python's [0, 0, 0]; write [0 for _ in range(3)].

    Python

    Underneath, this is Python with SymPy, running in your browser. A line that isn't calculator syntax runs as Python, one line at a time; separate statements with ;.

    def g(x): y = x + 1; return 2*y
    A Python function
    for i in range(3): print(i)
    Loops; printed output shows on the tape
    import math
    Imports
    def sq(n): return n^2
    ^ is a power here too (sq(3) is 9), not Python's XOR

    Otherwise Python lines are plain Python: nothing is implied, so write 2*x, not 2x. Only names defined with a = … and f(x) = … are kept when you reload.

    Keys

    ⏎
    Evaluate; on an empty line, repeat the last one
    ↑ ↓
    Select tape items, then: ⏎ insert, f exact/float, d degrees, c copy, ⌫ delete
    ⌃Z
    Undo deleting an entry, forgetting a variable, or :clear (not :reset)
    Tab
    Complete a name
    ?
    Function catalog
    ⌃M
    Math input
    ⌃C
    Stop a long computation

    Commands

    :vars
    What you've defined; ⌫ forgets one
    :clear
    Empty the tape; variables are kept
    :reset
    Empty the tape and forget everything
